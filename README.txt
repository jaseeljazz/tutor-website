DOHALEARN MULTI-PAGE TEMPLATE

Pages
- index.html: Homepage
- courses.html: Filterable course listing
- course-details.html: Dynamic course details using ?course=COURSE_ID
- checkout.html: Dynamic checkout and payment UI
- order-success.html: Order confirmation/receipt

Shared assets
- assets/css/style.css
- assets/js/main.js

Test flow
1. Open index.html.
2. Select Explore Courses.
3. Open any course details page.
4. Select Enrol Now.
5. Complete the checkout form.
6. The template redirects to order-success.html and shows the saved order summary.

Important
This is a front-end template. Card and payment-gateway fields are demonstration UI only. Real payments require a secure backend, merchant credentials, server-side validation, webhook verification, and a PCI-compliant integration with the selected provider.
